# 架构与维护

Python / Tkinter 界面，MSS 捕获可见像素，OpenCV / NumPy 在 CPU 上识别，PyInstaller 打包单文件 EXE。命令见 [开发指南](DEVELOPMENT.md)。

## 模块

| 模块 | 职责 |
| --- | --- |
| capture.py | 游戏窗口定位、DPI、遮挡检查与截图 |
| app.py | 后台识别循环、队列更新界面、轮次切换、提示音与退出 |
| detector.py、image_matching.py | 事件识别、匹配、确认与去重 |
| inventory.py、inventory_view.py | 背包定位、OCR、库存、图标和单价编辑 |
| storage.py、timing.py | SQLite 持久化与有效计时 |
| diagnostics.py | 日志、可选截图、补帧与去重 |
| maintenance.py | 用户目录、旧数据迁移和历史清理 |

## 关键约定

- Tk 只由主线程更新，后台结果经队列传递；轮次 epoch 拒绝过期结果。退出时等待工作线程结束，处理已确认结果后保存并关闭数据库。
- 事件至少三帧、持续 0.15 秒确认；连续清晰缺席 0.8 秒才重新触发。遮挡或未知画面不算消失；新轮次保留横幅锁存，避免重复计数。
- 陨星与流星雨独立统计。第一颗陨星启动计时，最近五次对应四段间隔；暂停和关闭时间不计入。恢复优先使用有效计时快照，避免系统时钟回拨影响。
- 背包读取须三帧一致且持续至少 0.7 秒。首次建立基线，后续记录消耗；仅完整紧凑列表可将消失球视为 0，失败读取不能当空背包。
- 支持单行背包；定位不得把右侧说明文字当作卡片。识别缓存以像素内容为依据，不缓存旧数量；新增图标后清空图标匹配缓存。
- 单价按球 key 存为十进制 TEXT，避免大整数溢出。成本按累计消耗乘当前单价求和；补充不冲减成本，未设置按 0，输入 0 删除单价。
- 单价回车或失焦保存；无效输入回车提示、失焦取消，Esc 取消。图标与单价跨轮次保留、按 Windows 用户共享，换游戏账号需手动新建轮次。
- 确认并持久化的新流星雨才播放提示音，恢复历史不播放。启动隐藏完成布局后显示，置顶默认关闭；内容变化不自动改变窗口高度。

## 数据与打包

数据位于 `%LOCALAPPDATA%/MeteorCounter`，不依赖 EXE 位置。旧版数据仅在目标无数据库时校验导入，不覆盖或合并。

诊断截图默认关闭；关闭后停止后续补帧，重新开启不补拍。日志、统计和球图标学习独立保存。写入与清理共用锁，保护未完成文件；清理拒绝符号链接和目录联接。Windows 目录重定向按逻辑数据边界处理，不能仅以 resolve 后路径不同判为外部链接。保留期限与手动清理范围见 [隐私说明](PRIVACY.md)。

单文件启动会解压，不复用旧 `_MEI`。资源和依赖许可随包保留，用户数据不打包。保留 `numpy.ma`（median 延迟加载）、OpenBLAS 和 Tcl 编码，避免破坏识别与中文显示。

## 识别边界

最多识别五行卡片；不同 UI、滚动或不完整列表、极端缩放不保证支持。完全被遮挡期间的事件无法还原；两次开包间同时消耗和补充只能观察净变化。短暂横幅可能不足确认帧数；首次 OCR 与重复帧的耗时须分别评估，合成缩放不能代表所有原生画面。
