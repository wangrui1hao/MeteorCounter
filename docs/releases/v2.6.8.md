本次更新增加咕噜球成本统计，精简界面，并修复单行背包的识别问题。

- 新增每种球的单价设置：双击就地编辑，回车或点击其他位置保存，Esc 取消；输入 0 恢复“未设置”。
- 本轮成本按各球消耗量乘以单价汇总，未设置按 0 计算，金额使用千位逗号分隔。
- 球图标和单价保存在本机，自动积累新球种，跨重启和轮次保留。切换游戏账号后请开始新一轮。
- 修复单行背包中选中蓝色球卡导致定位偏移、右侧说明文字被误识别为卡片的问题。
- 简化窗口标题和说明文字；目录与清理操作合并为两个右上角按钮，移除总消耗合计，固定表格列宽。
- 诊断截图默认关闭，按需开启；明确截图保留上限为 500 MiB。清理时保留当前轮次、球图标和单价。
