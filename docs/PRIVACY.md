# 数据与隐私

工具仅读取窗口位置和可见屏幕像素，本机识别；不读取游戏内存、不操作游戏、不采集麦克风、不上传数据。开发依赖下载和 GitHub 发布流程会联网。

## 本机保存

目录：`%LOCALAPPDATA%/MeteorCounter`，与 EXE 位置无关。

| 内容 | 用途与保留规则 |
| --- | --- |
| data/counts.sqlite3 | 轮次、计数、库存、计时和单价，长期保留 |
| data/ball_icons | 内置及学习到的球图标，长期保留；同一 Windows 用户共用 |
| data/logs、data/error.log | 运行及错误记录；普通日志保留 7 天，启动错误单独保存；路径可能含 Windows 用户名 |
| data/evidence、archive/evidence | 可选诊断截图，正常 3 天、失败 7 天，合计上限 500 MiB；写入中可能短暂超限 |
| cache | 单文件 EXE 解压缓存，不是截图 |

## 诊断截图

每次启动默认关闭，经勾选确认后仅本次开启。关闭会停止后续截图和补帧，不删除旧图；重新开启不补拍。统计、日志和小型球图标学习不受影响，暂停计数才暂停采集识别。

截图可能包含覆盖游戏的通知或其他窗口，遮挡检查不能保证过滤全部敏感内容。排错分享前检查 UID、昵称、聊天及本机路径，不要直接上传整个数据目录。数据为普通本地文件，没有额外加密。

## 清理

“清理缓存”确认后删除已结束轮次及已完成截图、今天之前的日志、超过一天的闲置解压缓存；保留当前轮次、当前截图、球图标和单价，并非删除全部数据。自动截图保留期限仍适用于当前轮次。
